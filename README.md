One satirical sentence roasting lawmakers who would regulate AI, crypto,
or the internet but cannot convert a file to PDF.

## Entry

> The committee writing the AI safety bill spent forty minutes asking IT
> how to save a Word file as a PDF — then voted to regulate the machines.

## Run

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt`. The program is
deterministic: it writes the same text on every run, with no network,
no randomness, and no input.
